# Forex Trading Platform

Complete forex trading platform with real-time signals, paper trading, and automation.

## Features
- 6 trading strategies with dynamic adaptation
- Real-time forex prices via ExchangeRate API
- Paper trading engine
- Performance analytics
- N8N automation workflows

## Deployment
This platform is deployed on Render using the included configuration files.

## Usage
1. Access the dashboard to view live prices and signals
2. Create manual signals or let the system generate them automatically
3. Monitor performance and trade history
4. Use N8N for automated notifications and reporting
